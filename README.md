# Fishindex_Bamberg

[![Deploy static content to Pages](https://github.com/Sysdocalex/Fishindex_Bamberg/actions/workflows/static.yml/badge.svg)](https://github.com/Sysdocalex/Fishindex_Bamberg/actions/workflows/static.yml)

An interactive fish encyclopedia for the Bavaria/Upper Franconia/Bamberg region (Regnitz River), featuring current fishing regulations.

Includes study materials for the Bavarian fishing exam.

Available in German and Czech.

Eine interaktive Fisch-Enzyklopädie für die Region Bayern/Oberfranken/Bamberg (Fluss Regnitz) mit aktuellen Fangbestimmungen.

Inklusive Lernmaterial für die Angelprüfung in Bayern.

Auf deutsch und ins Tschechische übersetzt.

Interaktivní rybářská encyklopedie pro oblast Bavorsko/Horní Franky/Bamberk (řeka Regnitz) s aktuálními předpisy pro rybolov.

Zahrnuje studijní materiály pro bavorskou rybářskou zkoušku.

Přeloženo do němčiny a češtiny.
